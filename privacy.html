Privacy Policy

Rise & Bias Factory · Effective date: October 20, 2026 · Home

1. Who we are and who uses this tool

Rise & Bias Factory ("the tool") is an internal command-line tool operated by the owner of the Rise & Bias YouTube channel. Its only user is the channel owner. It runs on the owner's own computer. It does not collect information about viewers or any other person.

2. Use of YouTube API Services

The tool uses YouTube API Services to upload videos, thumbnails and captions to the owner's own YouTube channel. By using the tool, the user agrees to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

3. Information the tool accesses, stores and uses

InformationHow it is usedWhere and how long it is kept
OAuth access and refresh tokens for the owner's Google account (scope youtube.force-ssl) To call the YouTube Data API on the owner's behalf. In a local file on the owner's computer, until the owner signs out or revokes access.
The signed-in channel's ID and title (channels.list) To confirm that the signed-in channel is the Rise & Bias channel before uploading. Shown on screen only; not stored.
The ID and link of each video and Short the tool uploaded To prevent duplicate uploads and to link each Short to the full video. In a local file on the owner's computer. Before each upload, IDs last confirmed 25 or more days ago are re-checked with the YouTube Data API (videos.list), and an ID is deleted if the video no longer exists, so no stored ID goes more than 30 days without being refreshed.
The status of an uploaded video (privacy, scheduled time, upload status, AI disclosure, made-for-kids) To confirm the upload settings. Shown on screen only; not stored.

The tool does not access or store information about other channels, other people's videos, comments, subscribers, viewers, or YouTube Analytics data.

4. Sharing

The tool does not sell, share, or transfer YouTube API Data to any third party. The tool uses other services (for example, AI services for writing scripts and generating narration and images) to produce videos; no YouTube API Data is sent to those services.

5. Cookies, advertising and third-party content

The tool does not use cookies, does not store information on viewers' devices, and does not show advertising or third-party content. This website does not use cookies or analytics.

6. Revoking access and deleting data

  • Sign out in the tool: running factory youtube-logout revokes the token with Google immediately, deletes the stored token, and deletes the stored video IDs and links.
  • Revoke access through Google: visit the Google security settings page at https://myaccount.google.com/permissions and remove access for this app. The owner, who is the only user, then runs factory youtube-logout to delete the stored data within 7 days.
  • To ask for deletion of any data, contact us (below). We delete it within 7 days.

7. Security

Tokens and stored data are kept only on the owner's computer, are excluded from source control, and are not uploaded to any server operated by us.

8. Changes

If this policy changes, the updated version will be posted on this page with a new effective date.
